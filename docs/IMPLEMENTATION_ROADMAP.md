# Networth — Implementation Roadmap

The project is delivered one phase at a time. Each phase has an acceptance gate; later systems must not be represented as complete before they are implemented and tested.

| Phase | Scope | Status |
|---|---|---|
| 0 | Setup and platform decisions | Recorded for the current browser-first shell |
| 1 | Core shell: navigation, nine placeholder workspaces and shared UI | **Implemented** |
| 2 | Simulation core: turn/date, seeded randomness, action validation, event log and local save/load | **Implemented** |
| 3 | Character, life, skills, time allocation, well-being and goals | **Accepted** |
| 4 | Household finance, ledger, budgets, cash flow, debt and net worth | **Accepted** |
| 5 | Employment and education | **Accepted** |
| 6 | Banking and credit | **Accepted** |
| 7 | Investment markets | **Accepted** |
| 8 | Property and collectibles | **Accepted** |
| 9 | Business operations | **Accepted** |
| 10 | Entrepreneurship, equity, acquisitions and governance | **In progress — specification locked** |
| 11 | News, events and interconnected economy | Not started |
| 12 | Financial freedom and endgame | Not started |
| 13 | Learning, balancing, accessibility and polish | Not started |
| 14 | Release candidate, backup/export/import and user acceptance | Not started |

## Phase transition rule

At each phase, report objective and status, files changed, behavior delivered, tests and results, acceptance criteria, known issues, decisions required and the proposed next phase. Do not begin a later phase until the current phase is accepted.
